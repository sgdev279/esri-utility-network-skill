# Knowledge inbox

A drop zone for raw Utility Network material that should end up in the skill but isn't written up yet: your own notes, lessons from a project, a summary of an Esri Community thread, a list of error codes you've hit.

## How to add something

1. Copy `_template.md` to a new file named `YYYY-MM-DD-short-topic.md`.
2. Fill it in — bullet points are fine.
3. Open a pull request (or attach the file to an ["Add UN knowledge" issue](https://github.com/sgdev279/esri-utility-network-skill/issues/new?template=add-knowledge.yml)).

## What happens next

A maintainer (or Claude with the skill-creator skill) folds the content into the right file under `references/`, credits the source, dates it, and deletes the inbox note in the same PR. Nothing in this folder is loaded by the skill, so notes here are safe to be rough.

## Please don't add

- Passwords, tokens, service URLs from your organisation, customer or network data
- Full copies of Esri documentation pages — link to them and summarise instead
