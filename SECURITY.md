# Security

## Reporting a vulnerability

If you find a security problem in the helper scripts or the skill content (for example a script that mishandles input, or reference content that would lead someone to expose credentials), please **don't open a public issue**. Use GitHub's private reporting: **Security → Report a vulnerability** on this repository. You'll get a response within 7 days.

## Content

Never put passwords, tokens, internal service URLs, customer names or network data in issues, pull requests or the knowledge inbox. Maintainers will remove it and may need to rewrite history.
