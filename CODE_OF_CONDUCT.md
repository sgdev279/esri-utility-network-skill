# Code of Conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and constructive. People here range from students to principal architects; everyone was new to the Utility Network once.
- Critique content, not people. "This parameter was renamed at 11.3 — here's the doc" is great feedback.
- No harassment, discrimination, personal attacks, or sharing others' private information.
- Credit your sources and other people's work.

Problems can be reported privately to the maintainer through GitHub (**@sgdev279**). Maintainers may edit or remove contributions and block participants who don't follow these guidelines.
